## Unity

SWArmada is built with [Unity](https://unity.com/). The project uses Unity's
Universal Render Pipeline, Input System, Netcode for GameObjects, Multiplayer
Services, UI, Shader Graph, and related engine packages. Unity and its packages
remain subject to Unity Technologies' applicable license terms.

## Retro Shaders Pro for URP

The CRT and retro display treatment uses
[Retro Shaders Pro for URP](https://www.danielilett.com/retro-shaders-pro/),
created by Daniel Ilett. Retro Shaders Pro is a commercially licensed Unity
asset and is not redistributed by this repository as a standalone package.

## Star Forge

[Star Forge](https://star-forge.tools/) and its public API data were used as a
reference for official ship, squadron, upgrade, objective, and rules content.
The associated project is maintained at
[Polkadoty/armada-list-builder](https://github.com/Polkadoty/armada-list-builder).

## Tabletop Simulator Armada source material

Portions of the model and texture preparation pipeline used source material
from
[Valadian/Jesse Berger's TabletopSimulatorIncludeDir](https://github.com/Valadian/TabletopSimulatorIncludeDir)
(local source commit `598f7741a7e3d09dd0e362b47914dd5d54ec1fe9`, authored by
Jesse Berger). The source snapshot examined for this release did not declare a
separate license for those assets. Their inclusion here is an attribution and
provenance statement, not a relicensing claim.
